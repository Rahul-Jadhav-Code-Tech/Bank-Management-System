# Bank Management Application

## Overview
This project is a console-based Bank Management Application developed in C++.  
The application simulates core banking operations using object-oriented programming and file handling techniques.

## Features
- Create new bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Display customer account details
- Store customer records using file handling
- Menu-driven interface for easy navigation

## Technologies Used
- C++
- Object Oriented Programming (OOP)
- File Handling

## Expected Outcome
The application provides a secure and functional banking system capable of performing deposits, withdrawals, and balance inquiries while maintaining persistent customer records.

## How to Run

### Compile the Program
```bash
g++ bank.cpp -o bank
```

### Run the Program
```bash
./bank
```
